# SailSense Live — Product Showcase

**Phone sailing instrument** — GPS, heel/trim, TWA, VMG, visual coach, offline recording.

This public repo documents the **product, go-to-market, and architecture**.  
It does **not** include the full mobile source code, keystores, or store binaries.

## Why it matters for AI Engineering hiring

- Sensor fusion + real-time coaching UX on-device  
- CSV export into analysis tooling ([Sailing-Analizer](https://github.com/carlob159-sys/Sailing-Analizer))  
- Domain AI/CV adjacency via sail-number detection ([waszp-sail-number-cv](https://github.com/carlob159-sys/waszp-sail-number-cv))  
- Clear product thinking: pricing, Play Store listing, privacy/terms
